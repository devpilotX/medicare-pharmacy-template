# MediCare — Pharmacy Website Template 💊

An **ultra-clean, mobile-first** website template for local pharmacies, clinics, and medicine delivery businesses in India.

Built by the **Pharmacy Digital Agency** — starting in Patna, made for every Tier 2 / Tier 3 city.

## ✨ Features

- 🩺 Soft, clinical, modern design (mint + slate palette)
- 🔎 Live medicine catalog search
- 📷 Prescription upload (WhatsApp handoff)
- 🛵 Home delivery request flow
- 💬 One-tap WhatsApp ordering
- 📍 Google Maps + Google Business ready
- 📱 Fully responsive, mobile-first
- ⚡ Zero build step — plain HTML/CSS/JS
- 🌐 Deploys to GitHub Pages in one click

## 🚀 Quick start

```bash
git clone https://github.com/devpilotX/medicare-pharmacy-template.git
cd medicare-pharmacy-template
# Open in any browser
open index.html
```

## 🛠️ Customize

Open `index.html` and edit the values inside the `<!-- CONFIG -->` block at the top:

- Pharmacy name
- Address
- WhatsApp number (international format, e.g. `919876543210`)
- Delivery radius
- Opening hours

The medicine catalog lives in `assets/medicines.json`. Add, remove, or update rows — the search updates automatically.

## 🌍 Deploy to GitHub Pages

1. Push to `main`
2. Repo **Settings → Pages → Source: `main` / `/ (root)`**
3. Site goes live at `https://<your-username>.github.io/medicare-pharmacy-template/`
